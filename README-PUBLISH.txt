LASITHA LEARNERS - MOBILE PUBLISH BUILD

This build is prepared for mobile phones first, while remaining responsive on desktop.

Included:
- Lasitha Learners main website
- Vehicle Parts section with Under The Hood links
- Changing full-screen background photos
- Comments/scroll effects from the website build
- Logo
- Exam Papers page + exam-paper.pdf
- Student registration/login/dashboard
- Admin page
- Supabase configuration files
- Responsive mobile navigation and touch-friendly forms/buttons

IMPORTANT:
1. Upload the contents of this folder to your hosting/repository root.
2. Keep index.html in the root.
3. Keep the assets folder beside index.html.
4. For GitHub Pages: Settings > Pages > Deploy from branch > main > /(root).
5. The site uses Supabase for registration/login, so the Supabase project must remain configured.
